## Deskripsi

Repositori ini digunakan untuk menyimpan dokumentasi dan hasil kegiatan perkuliahan mata kuliah **Konstruksi dan Evaluasi Perangkat Lunak**.

Mata kuliah ini membahas proses konstruksi perangkat lunak serta evaluasi kualitas perangkat lunak melalui penerapan metode, tools, dan praktik rekayasa perangkat lunak.

## Tujuan Perkuliahan

Perkuliahan ini bertujuan untuk membantu mahasiswa:

- Memahami konsep dan proses konstruksi perangkat lunak.
- Menerapkan praktik pemrograman dan pengembangan perangkat lunak yang baik.
- Menggunakan tools yang mendukung proses pengembangan perangkat lunak.
- Memahami konsep evaluasi dan pengujian perangkat lunak.
- Menilai kualitas perangkat lunak berdasarkan kriteria yang relevan.
- Mendokumentasikan proses dan hasil pekerjaan secara sistematis.
